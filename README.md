#  DARK FLICKER
 Dark flicker is a 2D Horror maze game 

 # GAME Story 
 the premise is that you have been abducted by some peoples and have been imprisoned in a deep underground dungeon filled with mazes , now your have escaped from your cell but still in the underground dungeon now you must navigate the dark maze layer by layer to escape the dungeon but you only have one light source and it will start to dim as time goes by , but it the light source exhaust itself you will lose yourself in darkness and will die
